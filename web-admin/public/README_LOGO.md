# إضافة Logo

يرجى وضع صورة الـ logo هنا باسم: **logo.png**

الـ logo يجب أن يحتوي على:
- اسم: **Chicken CANYADA**
- تاج ذهبي
- دجاجة ذهبية محاطة بإكليل
- نص "Crunchy food" في الأسفل
- خلفية سوداء

بعد وضع الصورة، سيتم عرضها تلقائياً في:
- Sidebar (لوحة التحكم)

إذا لم تكن الصورة موجودة، سيتم عرض emoji كبديل.
